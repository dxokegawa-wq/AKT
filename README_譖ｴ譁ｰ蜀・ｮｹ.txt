AKT活動審査アプリ v20260721-8

【修正内容】
1. 結果資料の点数表・順位表で、値が空白の月セルは「塗りつぶしなし」にします。
2. 単独の中間順位も「塗りつぶしなし」にします。
3. 1位＝赤、最下位＝灰色、1位・最下位以外の同率＝青のルールを維持します。
4. アプリ起動時は、v8で開始した審査が継続中の場合を除き、必ずトップ画面から始まります。
5. 審査途中で閉じた場合は、同じ店舗・途中位置から再開します。
6. 全店舗の審査完了後にアプリを開き直した場合は、トップ画面から始まります。

【確認方法】
画面タイトル横に「v20260721-8」と表示されていることを確認してください。

※旧版に残っている審査日・Excel取得データは「審査中」と判定しないため、更新直後もトップ画面から始まります。
